# ColorPicker
> Pick the Color as a Hex Code

```ts
import { ColorPicker } from "@neneys/ui"

ColorPicker(id, {....})
```

## Parameters

| Param | Value |
|:---------|:------:|
| value | Hex Code |
| orientation | [Axis](../components/MiscTypes.mdx#axis) |
| promptMode | [PromptMode](../components/MiscTypes.mdx#promptmode)
| onChanged | DoAction |
| showLabel | bool |

## Example

```ts
import { ColorPicker } from "@neneys/ui"

ColorPicker('#id', {})
```
