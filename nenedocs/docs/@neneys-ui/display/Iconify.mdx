# Iconify
> Uses Iconify API to Render Material Icon

[Icons List from Icon Sets from Iconify](https://icon-sets.iconify.design/material-symbols/?category=Material)

## Usage
```ts
import { Iconify } from "@neneys/ui"

Iconify("home", {})
```

## Parameters
| Param | Value |
|:---------|:------:|
| size | string |
| color | hex code |
| prefix | Iconify Prefix (prefix + "/" + name) |
