## TextStyle

```ts
import { TextStyle } from "@neneys/ui"

TextStyle({
    height: 1.0
})
```

| Param | Value | Default |
|:---------|:------:|:------:|
| height | float | 1.0 |
| fontSize | float | 14 |
| fontWeight | [FontWeight](#fontweight) | .w400 |
| color | string | [Colors.black](#colors) |
| decoration | [TextDecoration](#textdecoration) | TextDecoration.none |
| fontStyle | [FontStyle](#fontstyle) | FontStyle.normal |

## AssetImage
> Loads Image from the Assets Folder (during compilation)

```ts
import { AssetImage } from "@neneys/ui"

AssetImage("assets/nene.png")
```

## NetworkImage
> Loads Image from the Network / URL

```ts
import { NetworkImage } from "@neneys/ui"

NetworkImage("https://example.com/network.png")
```

## BoxDecoration

```ts
import { BoxDecoration } from "@neneys/ui"

BoxDecoration({..})
```

| Param | Value | Default |
|:---------|:------:|:------:|
| color | Hex Code | #FFFFFF |
| image | [AssetImage](#assetimage), [NetworkImage](#networkimage) | none
| radius | int | 1
| borderColor | Hex Code | #FFFFFF |
| borderWidth | int | 1

## EdgeInsets

```ts
import { EdgeInsets } from "@neneys/ui"

EdgeInsets.all(10)
```

### .all
.all(integer) from all LTRB Sides

### .fromLTRB(left, top, right, bottom)
All must be in Integer
