# Components

> Components shape and show how the app looks and functions - @26_kwee (Wise Quotes)

# How are Components Registered?

> NeneUI Components are structured in this way

```ts
import { ComponentName } from "@neneys/ui"

ComponentName('#ID', {
    arguments: 1
})
```

#ID -> NeneUI Registers an ID with each or most of the components so that they can be manipulated or fetched easily.
