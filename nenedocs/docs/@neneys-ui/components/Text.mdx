# Text

> As the Name Suggests, Text!

```ts
import { Text } from "@neneys/ui"

Text('#text', { text: "Konnichiwaaa!~ World!!" })
```

## Parameters

| Param | Value |
|:---------|:------:|
| text | `String` or `Variable` |
| align | [TextAlign](MiscTypes.mdx#textalign) |
| overflow | [TextOverflow](MiscTypes.mdx#textoverflow) |
| style | [TextStyle](MiscTypes.mdx#textstyle) |


## Example

```ts
import { Text, TextStyle } from "@neneys/ui"

Text('#Text', { text: "Hello World", style: TextStyle({}) })
```
