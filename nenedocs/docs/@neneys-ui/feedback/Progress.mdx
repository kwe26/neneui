# Progress
> Lil Bar

```ts
import { Progress } from "@neneys/ui"

Progress('#id', {..})
```

## Parameters
| Param | Value |
|:---------|:------:|
| progress | double |
| color | #HEX CODE |
| backgroundColor | # HEX Code |

## Example

```ts
import { Progress } from "@neneys/ui"

Progress('#id', {
    progress: 50,
    color: "#5f0",
    backgroundColor: "#FFFFFF"
})
```
