# Web Platform Setup
> @neneys/ui also supports Flutter Web out of the box with SEO (Optional) Support via PHP.

## Compile Flutter Web
```bash
flutter build web
```

## Setting Up with NeneServer
1. Copy `build/web` files into an `fluweb` Directory.
2. Modify NeneServer Arguments
```ts
flutterWebPath: "__path t0 fluweb__",
```

# DONE!
Now, NeneServer is linked with Flutter Web version!
