# Neneys UI - Plugins
> Plugins support for NeneUI is in very early stage with the plugins below are only created for demonstration purposes and are not yet stable..


# Available Plugins
- @neneys/payments
> Allows Payments to be accepted in NeneUI and WIP. To support more payment gateways natively in NeneUI soon!

- neneui_video_plugin
> Uses media_kit to Play videos in NeneUI. Has a WIP Wrapper to allow Video Playing, Does not works in Some Platforms

# Is it Possible to Create Custom Plugins?
> No, As of now, it is not possible to create custom plugins for NeneUI but it is planned to allow creation of custom plugins in the future.
