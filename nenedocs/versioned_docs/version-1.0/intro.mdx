# Welcome - @neneys
> @neneys Comprises of @neneys/ui and @neneys/payments and more coming soon.

- @neneys/ui
> It's an UI Library for Server-Side Rendered Apps and every operation and interface is controlled from server-side via TypeScript and there's 0-WebView Used for Widgets Rendering. Everything is rendered Natively.

- @neneys/payments
> It's an Payments API Which includes Razorpay and more soon. An Single Payments Package to Create and Initiate Payments (It is NeneUI-first).
