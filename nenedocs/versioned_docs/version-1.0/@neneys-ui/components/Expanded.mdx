# Expanded

> As the Name Suggests, an Sized Box!

```ts
import { Expanded } from "@neneys/ui"

Expanded('#id', { child:.. }),
```

## Parameters

| Param | Value |
|:---------|:------:|
| child | Widget |
| flex | int |

## Example

```ts
import { Expanded, Empty } from "@neneys/ui"

Expanded('#id', { child: Empty() })
```
