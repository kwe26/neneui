# Setup Server-Side Backend

### Install Package
> Install the Latest @neneys/ui Package from the Package Repository
<Tabs>
  <TabItem value="bun" label="Bun" default>
    ```bash
    bun install @neneys/ui
    ```
  </TabItem> 
  <TabItem value="npm" label="NPM">
    ```bash
    npm install @neneys/ui
    ```
  </TabItem> 
</Tabs>

## Setup Project Strucutre
```txt
Project Root/
├── interfaces/
├── callbacks/
└── index.ts
```

### Create Files

<Tabs>
  <TabItem value="index_ts" label="index.ts" default>
    ```ts
    import { NeneServer } from "@neneys/ui"

    NeneServer({
      port: 3500,
      uiPath: "./interfaces",
      verbose: true,
      callbackPath: "./callbacks"
    })
    ```
  </TabItem>
  <TabItem value="interfaces_home.ts" label="interfaces/home.ts">
  :::warning
    You must use the initial route as /ui/main no matter what.
  :::
    ```ts
    import type { Request, Response } from "express";
    import { AppBar, Colors, Column, CrossAxis,FontWeight, Iconify, MainAxis, SingleChildScrollView, Scaffold, Text, TextStyle, TextAlign } from "@neneys/ui";

    export const path = "/ui/main"
    export function run(req: Request, res: Response, pass: any) {
        let scaffold = Scaffold('#mainScaffold', {
            appBar: AppBar('#appBar', {
                leading: Iconify("home", { color: Colors.white }),
                title: Text('#appBarText', { text: "NeneUI Example", style: TextStyle({
                    color: Colors.white
                }) })
            }),
            preActions: [],
            body: SingleChildScrollView('#sch', {
                child: Column(
                    '#mainColumn',
                    {
                        mainAxisAlignment: MainAxis.center,
                        crossAxisAlignment: CrossAxis.center,
                        children: [
                            Text('#textNene', {
                                text: "Welcome to NeneUI!",
                                align: TextAlign.center,
                                style: TextStyle(
                                    {
                                        fontWeight: FontWeight.w600,
                                        fontSize: 32
                                    }
                                )
                            }),
                            Text("#neneText2", {text: "You can start modifying example_ui/home.ts to add or remove more Widgets and Customize it with your needs!!!"})
                        ]
                    }
                )
            })
        });

        res.json(scaffold);
    }
    ```
  </TabItem>
</Tabs>

## Run & Check
> Executing the index.ts Server.
<Tabs>
  <TabItem value="bun" label="Bun" default>
    ```bash
    bun index.ts
    ```
  </TabItem> 
  <TabItem value="node" label="Node.js (v23.6.0 +)">
  :::warning
    Since Node.js Executes .ts without TypeChecking it is absolutely not recommended to use Node.js to directly execute, instead use tsc to compile into .js and execute or use Bun.sh
  :::
    ```bash
    node index.ts
    ```
  </TabItem> 
</Tabs>

### Check
#### Run a Quick cURL Test
```bash
curl http://localhost:3500/ui/main
```
*You will see an JSON Response that directly corresponds to the interface code we just wrote.*
