# Nene UI Runtime

Build Flutter interfaces dynamically from a JavaScript server.

## Features

- Server-driven UI
- JavaScript backend
- Flutter rendering
- Dynamic widgets

## Installation

```bash
bun add neneui
```

## Run Sample

```bash
bun run server_test.ts
```

```bash
cd ./flutter_render/example && flutter run -d
```
