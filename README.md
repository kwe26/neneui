# Nene UI Runtime

Build Flutter interfaces dynamically from a JavaScript server.

## Features

- Server-driven UI
- JavaScript backend
- Flutter rendering
- Dynamic widgets

## Getting Started

# Requirements
- Flutter SDK (3.38.6 or above)
- Bun.sh 1.3.x
- JavaScript & Dart Knowledge obv

## Setting Up Backend

```bash
bun add @neneys/ui
```


```bash
cd ./flutter_render/example && flutter run -d
```
